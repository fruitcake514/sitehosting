# Hosting Manager

This project enables you to deploy a simple hosting manager app inside Docker for managing WordPress sites, PHP-based sites, and static websites. It also includes an in-browser code editor and auto-generated Nginx configurations.

---

## Prerequisites

- **Docker**: Ensure Docker is installed on your system.
